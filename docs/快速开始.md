# 调研宝后端服务 - 快速开始

## 项目简介

调研宝(Survey Pal)后端服务是一个基于 FastAPI 的问卷调研系统后端 API，支持问卷创建、答题提交、实时聊天和数据统计等功能。

当前版本：**v0.1.0** (开发阶段)

---

## 环境要求

### 必需
- **Python**: 3.13+
- **uv**: 包管理工具 (推荐 0.7.6+)

### 可选(后续功能需要)
- **PostgreSQL**: 16+ (数据库)
- **Redis**: 7+ (缓存和消息队列)

---

## 快速启动

### 1. 克隆项目

```bash
git clone <repository-url>
cd survey-pal-backend-server
```

### 2. 安装依赖

项目使用 `uv` 管理依赖，会自动创建虚拟环境：

```bash
# uv 会自动读取 .python-version 并使用 Python 3.13
uv sync
```

### 3. 启动开发服务器

有三种启动方式：

#### 方式一：使用 FastAPI CLI (推荐)

```bash
uv run fastapi dev main.py
```

启动后访问：
- API 端点: http://localhost:8000/api/v1/test
- 交互式文档: http://localhost:8000/docs
- ReDoc 文档: http://localhost:8000/redoc

#### 方式二：使用 Uvicorn

```bash
uv run uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

#### 方式三：直接运行 Python (如果 main.py 包含启动代码)

```bash
uv run python main.py
```

## 常见问题

### Q: 如何更换 Python 版本？

修改 `.python-version` 文件后重新运行 `uv sync`。

### Q: 端口被占用怎么办？

```bash
# 查找占用 8000 端口的进程
lsof -i :8000

# 杀掉进程
kill -9 <PID>

# 或使用其他端口启动
uv run fastapi dev main.py --port 8001
```

### Q: 如何重置依赖？

```bash
# 删除虚拟环境
rm -rf .venv

# 重新安装
uv sync
```

### Q: 为什么使用 uv 而不是 pip/poetry？

- **更快**: 比 pip 快 10-100 倍
- **可靠**: 完整的依赖解析和锁定
- **简单**: 单个工具完成所有包管理任务
- **兼容**: 支持标准 pyproject.toml
